# Keysight 33500B Waveform Generator Controller

A well-structured Python GUI application following the MVC (Model-View-Controller) design pattern to control Keysight 33500B waveform generators. The application provides a user-friendly interface for setting parameters, managing channels, running test sequences from Excel files, and more.

## Features

- **Device Connection**: Easily connect to Keysight waveform generators via VISA interface.
- **Waveform Control**: Supports sine, square, triangle, and ramp waveforms.
- **Parameter Configuration**: Set frequency, amplitude, offset, and phase parameters directly.
- **Channel Management**: Independently control output channels.
- **Test Sequences**: Run automated test sequences from Excel files.
- **Excel Template**: Generate customizable test sequence templates.
